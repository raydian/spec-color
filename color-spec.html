1色彩角色体系（60-30-10）

任何一页/一帧画面，先把颜色按"角色"分配，再谈好看。一套视觉里只允许 1 个主色，避免品牌漂移。

主色 60%
辅色 30%
强调 10%
角色占比职责禁用
主色 Primary≈60%品牌识别、封面/首屏大面积铺底、核心色块不可超过 1 个主色
辅色 Secondary≈30%内容分区、图表、次级强调、同屏过渡不与主色抢面积
强调色 Accent≈10%CTA 按钮、关键数据、点睛撞色不可贪多，单点使用
中性层 Neutral按需文字、背景、分隔线（黑/白/灰 + 纸色）避免"灰底灰字"
顺序铁律：先定主色 → 再选辅色 → 最后点强调。强调色必须与主色有足够对比（见第四节），否则"点睛"会变成"糊点"。

2五大和谐关系

取自本色谱每条颜色的 pairings 结构。配色不确定时，按以下五种关系之一组织，基本不会翻车。

建议：品牌长期物料优先 同色系深浅 或 中性平衡（稳）；促销活动可用 互补色 / 三角色（提神），但强调色面积严守 10%。

3分媒介规范

印刷品核心约束

维度规范
色彩模式交付 CMYK，不要直接给屏幕 RGB。RGB 直转 CMYK 普遍偏暗、偏灰，必须打样校准。
品牌主色建议定 专色 / Pantone，保证不同批次、不同纸张下一致；四色叠印难复现高饱和红金。
出血与边距出血 3mm；关键文字/Logo 距裁切边 ≥5mm，避免裁掉。
纸张影响铜版纸显色艳、胶版纸偏灰、特种纸吸墨深——同一 RGB 跨纸差异大，每种纸都要打样。
字号下限正文 ≥ 8pt；反白小字 ≥ 9pt；极细宋体屏幕好看但印刷易断笔。
叠印避免大面积高饱和色叠印；深色块叠印易"脏"。黑字用单色黑或叠印黑需明确标注。

屏幕 / 投影核心约束

维度规范
色彩模式用 sRGB。投影仪亮度低、对比衰减，提高明度差比提高饱和度更有效。
背景策略二选一：浅底深字 或 深底浅字；严禁灰底灰字、低对比渐变上的白字。
投影对策主色饱和度下调 5–10% 提对比；关键文字加 描边/阴影；远程会议场景默认降饱和。
图表配色离散类别：主色 + 邻近辅色 + 强调；避免红绿同屏（红绿色盲）。顺序数据：用单色明度梯度。
字体标题 ≥ 28pt，正文 ≥ 18pt；中文用思源/苹方等黑体，禁用衬线小字。
一致性母版锁定主色与中性层；每页主色不变，仅换辅色分区。

动态影像核心约束

维度规范
色彩空间导出 sRGB / Rec.709；HDR 物料单独定标，不与 SDR 混剪。
安全区文字/关键信息置于中心 90% 安全框，避开黑边与平台裁切（尤其竖屏 9:16）。
字幕半透明黑底 #000000AA + 白字 #FFFFFF + 1–2px 描边；勿用纯色大字无描边，易被复杂背景吃掉。
动态对比运动画面降低主色饱和、提高关键元素对比；闪烁频率 < 3Hz，避免光敏风险。
调色一致全片统一 LUT / 色温；品牌主色在片头、片尾、角标固化出现。
跨比例横屏 16:9 与竖屏 9:16 各出一版，主色占比保持一致，不简单裁切。

4对比度与可读性

  • WCAG 阈值：正文文字对比度 ≥ 4.5:1；大字号（≥18pt 或 ≥14pt 粗体）≥ 3:1。
  • 本色谱已内嵌对比提示：每条颜色的 fontColor 字段即"该底色上的推荐文字色"（多为 #343333 深字），可直接采用。
  • 色盲友好：不单独用红/绿传达信息；叠加 形状 + 文字 + 位置 三重编码。
  • 视频额外：字幕与画面主体也需满足 3:1，靠描边/底栏保证。
把"文字色"当成设计决策，而不是默认黑或默认白。下方模板实时计算背景—文字对比度，绿色=达标。

六套可直接套用的配色。每张卡显示主/辅/点/背/文五色与"背景—文字"对比度，绿色 ✔ 表示满足 WCAG 正文标准。

6禁忌与建议

绝对禁忌

  • 一套视觉出现 超过 1 个主色（品牌漂移）。
  • 灰底灰字 / 低对比：投影、印刷、视频字幕都先测对比度。
  • 印刷物料 直接交付 RGB，或把屏幕色当印刷色用。
  • 视频使用 无描边纯色大字幕。
  • 每页/每帧 更换主色，观众无法建立品牌记忆。
  • 高饱和等大色块 长时间静止停留，造成视觉疲劳。

推荐做法

  • 先用中性层搭骨架，再上主色，最后点强调。
  • 不确定配色时，从"五大和谐关系"中任选一种组织。
  • 印刷打样、PPT 投屏预演、视频多端预览，三者都做一遍。
  • 建立一份品牌色卡（主/辅/点 + 对应 CMYK/RGB/HEX），全员共享。
